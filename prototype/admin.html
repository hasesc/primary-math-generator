🚨 产品红线与防失忆工作流 (GEMINI.md)

一、每次修改代码后的强制三步曲

  1. 运行 node scripts/manage.mjs snapshot "改动说明"：自动跑通 8 大测试套件、更新本看板数据并提交 Git 快照。
  2. 在 CHANGELOG.md 记录本次新增或修改的单元考法，同步更新 PROJECT_STATUS.md 待办勾选。
  3. 若修改了前端 JS/CSS，递增 index.html / admin.html 中的 ?v= 版本号防缓存。

二、绝对不可触碰的合规与技术红线

  • 绝不做题库、不存题目：个人主体按微信小程序“工具”类目申报，纯算法实时生成，无任何题目持久化存储。
  • 合规文案红线：界面与导出物只用“单元同步练 / 练习卷 / 实时生成 / 导出打印”，严禁出现“真题 / 试卷 / 小升初 / 名校 / 提分 / 课程 / 讲解 / 辅导”。
  • 引擎参数铁律：config.digits 四键（add/subtract/multiply/divide）必须齐全，termCount 必传。
