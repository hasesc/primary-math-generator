# 📐 Primary Math Practice Generator (小学数学 · 单元同步练习生成器)

> **专为小学生家长与数学老师设计的纯前端开源练习纸生成排版工具。**  
> 覆盖人教版 1~6 年级上下册共 **93 个单元**，包含口算、竖式、时钟、统计图表、方格平移对称与几何作图。  
> 纯算法本地实时计算，**无数据库、无网络题库、无会员充值、零广告、无水印，一键 A4 高清排版打印**。

---

## ✨ 核心特性

- 🎯 **人教版 1~6 年级 93 个单元全覆盖**：从一年级数的认识与钟表，到六年级圆柱圆锥与比例，紧扣义务教育数学课程标准。
- ⚡ **真正的“无限题库”（纯算法实时生成）**：不存任何一道静态死题。每次点击“重新生成”，都是由算法生成的全新数字与图形，杜绝背题。
- 📊 **丰富的高清矢量几何与图表题（全网罕见）**：自研纯 SVG 矢量渲染引擎，完美支持：
  - 🕒 **钟表认读与画指针**
  - 📊 **单/复式条形统计图、折线图、扇形图**
  - 📐 **方格纸平移、轴对称、旋转作图**
  - 🧊 **三视图、圆柱圆锥展开、周长与面积**
- 📈 **三档阶梯考法（Easy / Medium / Hard）**：基础夯实、进阶拓展、思维冲刺，满足不同层次学生的练习需求。
- 🖨️ **工业级 A4 双栏矢量排版**：严格按照正规出版社教辅规范设计字号、行距与答题留白，内置打印样式表，支持浏览器直接 `Ctrl + P` 完美无缝打印。
- 🧮 **每日一练专项**：
  - **口算天天练**（7 个专项梯度，分栏紧凑）
  - **竖式天天练**（10 个专项梯度，含加减乘小数对齐与除法标准竖式框）
- 🛡️ **轻量纯粹、绿色安全**：纯前端原生 JavaScript，无任何第三方沉重依赖，不收集任何个人隐私，零后台成本。

## 🚀 快速开始

### 方式 1：本地双击直接运行（推荐）
如果你已经安装了 [Node.js](https://nodejs.org/)：
1. 下载或克隆本项目到本地。
2. 双击运行根目录下的 `双击启动出题器.bat`。
3. 浏览器将自动打开出题工作台：`http://localhost:3000`。

### 方式 2：静态文件服务器
在项目根目录下执行：
```bash
node scripts/serve.mjs
```

## 🧪 自动化测试体系

本项目包含完整的自动化防御机制，确保每次考法调整与算法修改零回归：
```bash
node scripts/manage.mjs test
```
- `smoke-test`：全单元冒烟测试
- `coverage-test`：93 单元覆盖率扫描
- `correctness-test`：数学答案可计算性与正确性复算
- `daily-practice-test`：口算与竖式专项测试
- `difficulty-gradient-test`：三档难度数值与考法梯度校验
- `rotation-test`：考法轮转不重复测试
- `regression-test`：典型边界回归测试
